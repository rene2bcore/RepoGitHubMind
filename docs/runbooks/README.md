# Runbooks

El runbook principal, con el índice por síntoma, está en [`../runbooks.md`](../runbooks.md).

Esta carpeta es para procedimientos largos que no caben allí: un despliegue con muchos pasos, una migración de datos, una rotación de credenciales de un servicio externo. Uno por fichero, y cada uno con la fecha de la última vez que se ejecutó de verdad. Un procedimiento que no se ha ejecutado nunca lo dice en su primera línea.
